Clarity: BC Public Service Web Theme, version 1.19.0. Theme patterns and custom blocks use the prefix **PSW** followed by one space. This identifies the project-developed theme; it does not designate a standard for every B.C. government website.

## Navigation page starter

Select the **Navigation page** template on an empty page. In the page settings sidebar, open **Navigation page setup** and select **Insert navigation page starter**. A default empty paragraph is also treated as empty content.

The template already supplies automatic child-page cards. The action adds the starter's optional manual related-link content below them and omits a second automatic card group. It respects insertion permissions and block locks, rechecks the current page before inserting, and becomes unavailable once content exists. It does not replace an existing page body.

This starter is separate from the general pattern picker. The retired Home, standard-content and guide/reference starters are not setup options.

## Search and layout controls

Search by the visible feature or by **PSW** or **Clarity**. Keywords include singular/plural forms and useful synonyms for card, icon, numbered, image, column, feature, callout, box and tab. A pattern can be listed in more than one relevant category.

- **PSW Text columns** provides two columns, three columns or fit available space, with optional separators, through **Block > Pattern layout**
- **PSW Comparison cards** provides one configurable comparison layout with a **Show icons** option in **Pattern layout**
- **PSW Card: outlined text** provides a neutral bordered container with padding and a transparent background; headings, paragraphs, lists and optional links remain ordinary editable content

Column counts and icon visibility are settings within these patterns. Existing instances of the earlier summary and comparison patterns remain compatible.

## Headings and section spacing

Main content section H2s use 2rem text and a short yellow line above the heading. The line also applies to headings above an entire accordion, card, tab, table, step or text-column section. H3 and lower headings receive no yellow heading line.

Navigation labels, feedback prompts, individual cards, callouts and framed introductions use their component typography without the heading line. Heading levels continue to express the document structure. Changing a heading between H2 and H3 in an unboxed section changes the line treatment automatically.

The line is 2rem wide and 3px high, with a .75rem gap below it. Section spacing is 4rem, reduced to 3rem at viewport widths up to 600px. The outer pattern carries the larger gap; its first section heading has no additional top margin. Ordinary pattern spacing and component padding remain separate.

The existing section wrappers, unboxed native Group blocks and editor root determine the section treatment. Enclosing navigation, cards, panels, and Group blocks with background or border colours suppress it. Native text alignment aligns the line; forced-colour mode uses the system foreground. Individually saved styles and Global Styles may still override theme defaults.
